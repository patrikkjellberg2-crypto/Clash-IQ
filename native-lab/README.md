# Clash IQ Native Lab

An isolated Android-native prototype built with Kotlin and Jetpack Compose. It does not use a WebView and does not modify the existing app.

## Open and run
Open the `native-lab` directory in Android Studio, allow Gradle sync, then run the `app` configuration on an emulator or Android device.

This is the first native UI foundation. Current screens use local sample data; API integration and the remaining app screens are not implemented yet.
